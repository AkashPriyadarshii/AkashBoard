DESIGN INVARIANTS

Guaranteed invariants.

OFFLINE-FIRST PRIVACY PROTOCOL

On-device Whisper AI speech recognition runs 100% locally on device silicon without internet. Audio buffers are processed in volatile RAM and zeroed immediately. External network access is strictly opt-in when you supply your own API key (BYOK).

NON-BLOCKING COROUTINE DISPATCH

All AI model inference, speech VAD, and dictionary searches execute on background coroutines (Dispatchers.Default). The UI thread is never blocked, maintaining a consistent 120 FPS typing experience.
