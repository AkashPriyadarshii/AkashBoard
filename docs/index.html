What's Inside

Everything. Nothing extra.

12 weeks of engineering compressed into 2 days. Every feature works. Every test passes.

🧠

Rust Prediction Engine

N-gram model with unigram, bigram, and trigram support. Predictions return in <1ms via JNI. Learns your words, your patterns, your context.

✍️

Swipe / Glide Typing

Draw a path across letters. Bezier trail renders at 120fps. Order-preserving dictionary match finds your word.

🔧

Smart Autocorrect

25+ built-in typo corrections. Edit distance matching against known words. Learns from your corrections. Undo with backspace.

🎨

5 Built-in Themes

Dark, Light, Neon Cyber, Minimal, Sunset. JSON format — create and share your own. Live switching, no restart.

📊

Typing Analytics

WPM, accuracy, session tracking. Typing DNA fingerprint. Time-aware predictions that know your schedule.

🔒

Zero Tracking

No INTERNET permission. No accounts. Privacy dashboard shows exactly what's stored. Nuclear delete wipes everything.

📋

Clipboard History

Room DB-backed. Pin items. Search. Tap to paste. 50-item history with configurable limits.

🎙️

Voice Input

Android SpeechRecognizer wrapper. Works offline on most devices. One tap to start dictating.

⚙️

Full Settings App

Typing, Appearance, Privacy, About. Every setting has sensible defaults. Export/Import for data portability.

For Developers

Build it yourself.

Clone, build, install. Three commands.

# Clone the repo
git clone https://github.com/AkashPriyadarshii/AkashBoard.git
cd AkashBoard

# Build the Rust engine
cd engine && cargo ndk -t arm64-v8a build --release

# Build and install
cd .. && ./gradlew assembleRelease
adb install app/build/outputs/apk/release/app-release.apk
