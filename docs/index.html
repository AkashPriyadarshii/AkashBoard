What's inside

Every feature works. Nothing is vaporware.

Each item below ships in v1.0.0 today — covered by tests, auditable in source.

01

Rust prediction engine

N-gram model (uni/bi/trigram) behind JNI. Predictions return in under a millisecond and learn from your own words — never leaving the device.

02

Swipe typing

Draw a path across letters. Bezier trail renders at up to 120fps. Order-preserving dictionary match finds your word without proprietary blobs.

03

Smart autocorrect

25+ built-in typo fixes plus edit-distance matching against your vocabulary. Backspace undoes a correction.

04

Five themes, JSON format

Dark, Light, Neon Cyber, Minimal, Sunset. Edit the JSON to make your own — live switching, shareable files.

05

Clipboard history

Room DB-backed. Pin items, search, tap to paste. 50-item history with configurable limits — stored locally only.

06

Zero tracking, provable

No INTERNET permission at all. Privacy dashboard shows exactly what's stored. Nuclear delete wipes everything in one tap.

07

Voice input & analytics

Offline SpeechRecognizer wrapper. WPM, accuracy, session stats — computed on-device, exportable whenever you want out.

For developers

Build it yourself in three commands.

# clone + build rust engine
git clone https://github.com/AkashPriyadarshii/AkashBoard.git && cd AkashBoard
cd engine && cargo ndk -t arm64-v8a build --release

# assemble + install
cd .. && ./gradlew assembleRelease
adb install app/build/outputs/apk/release/app-release.apk
