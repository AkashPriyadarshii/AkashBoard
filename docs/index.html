AkashBoard is the ultimate privacy-first Android keyboard. This OEM manual contains maintenance and repair procedures for the predictive text assembly. The unit operates entirely on-device using a blazing-fast, Rust-compiled ARM64 prediction engine.

Verifiable Source Build Procedure

For operators requiring cryptographic proof of the binary, follow the reproducible build instructions.

  1. Clone the upstream repository via Git:
    git clone https://github.com/AkashPriyadarshii/AkashBoard.git
  2. Install cargo-ndk for Rust cross-compilation target ARM64.
  3. Initialize the Gradle wrapper and assemble the release variant:
    ./gradlew assembleRelease
  4. Verify the SHA-256 hash against the published manifest.
  5. Deploy to device:
    adb install -r app/build/outputs/apk/release/app-release.apk

Warnings & Cautions

WARNING: STRICT ISOLATION PROTOCOL

Under NO circumstances should android.permission.INTERNET be added to the AndroidManifest.xml. This unit operates in a vacuum. Modifying this constraint compromises the integrity of the device and violates the core design specification.

CAUTION: UI THREAD BLOCKING

All Rust Engine predictions must be executed via background coroutines (Dispatchers.Default). Calling JNI bridges directly on the main thread will induce stutter and frame drops during high-speed typing.
