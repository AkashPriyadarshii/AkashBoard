AkashBoard

Privacy-first Android keyboard with a Rust prediction engine
bridged via JNI/NDK

Type on the keys below (hardware or mouse — nothing leaves your browser).

Suggestion: demo runs in your browser, nothing sent anywhere

Focus visible: serika-yellow ring (3px outline)

Privacy

No Internet. The IME lives entirely on device. Zero network traffic. No telemetry. No cloud uploads. All prediction happens in a Rust engine compiled to .so.

Your model. {config_dir}/model.json is your personal corrections ledger — serde(default) loads old files, backs up personal corrections persistently.

203 engine tests. Full test suite runs locally (cargo test --release) — 100% offline, every commit. No CI-only gates.

Features

Swipe

Glide-type across keys — path matching against a dictionary, closest-key fallback.

Corrections

On space/punct, if the word differs from what you typed, it's replaced silently and learned as an error pattern.

Emoji

Scrollable grid — drag vertically to see all rows. Fixed-height panel clamps to visible rows.

One-handed

Shift width fraction to 0.8f, offset thumb side. Off clears. A11y node provider present.

Clipboard

Copy text to clipboard from the keyboard panel. No internet — local clipboard bridge only.

Themes

Canvas slate, keycap carbon, serika accent on focus. 4-colors only. No gradients. No decorative chrome.
